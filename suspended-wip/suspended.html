SUSPENDED

Suspended in a Gust is a web-based interface that allows users to examine each frame of a risograph animation.

The project aids in users’ understanding of how change over time is visualized in a 2D medium. The interface features a navigable carousel of high-quality scans of each frame of a risograph printed animation which users can examine closely using zoom and pan features. By comparing and contrasting adjacent still frames from the sequence, users can see how differences in scale, depth, position, rotation, shape, & more can be animated.
